## Follow-ups (below the bar)

1. **A character made while the head message is the greeting vanishes if the reader then swipes the greeting.** Create attaches the blocks to the head reply (as before 2.9.0). The new Home card and hold dialog make this window easier to hit: new chat, Create your character from Home, then swipe to another greeting: both blocks disappear with no message (no Problems line); swiping back brings them back, and the Home card returns meanwhile. With "Create your character, then send" the message goes out immediately, so that path is safe. Repro: `/tmp/claude-0/-home-user-inventory-block/3572f065-fdf3-5cf4-88eb-a15358a57ebe/scratchpad/rv171/scripts/greet.mjs` (`swipe-new` and `swipe-existing`: `[alex, alex-s]` -> `[]` -> back). Suggest a one-line note in the wizard or the Home card, or anchoring the player's first character to the chat rather than the head reply.
2. **`- party <the player's own name>` marks the player's character Left and drops it from the dice sheet.** There is no reader-side way to undo it except swiping the reply (the Left field is not editable on the Party card). Needs the narrator to write the player's name on a `- party` line, so I did not count it as ordinary use. Repro: `/tmp/claude-0/-home-user-inventory-block/3572f065-fdf3-5cf4-88eb-a15358a57ebe/scratchpad/rv171/scripts/leaveyou.mjs` (sheet `['You']` -> `[]`, `left: true`). Suggest refusing `- party` for the character named like the persona.
3. **A Re-read of an old capped reply now pays what the story wrote.** Same chat as above, Re-read of the first capped reply: coin 1436 -> 1836 and Arrow 20 -> 60 (main keeps it capped at 100 / 20 while the setting is on). Replay, swipe, delete and reload stay as written, so "old chats replay exactly as they were" is true; Re-read is a fresh read of the text. Worth one sentence in the CHANGELOG/Money help.
4. **The Companions-who-join default (Ask) adds the `party` grammar line to the static prompt of every existing RPG chat that has a character**, and the line also appears the moment a story gets its first Character block (the kind is enabled only once a party exists). One cache break per chat, not per reply; the RPG-off and Companions-Off prompts are unchanged (see above).
5. Home's "Your character" card is drawn from the RPG's widget; if the RPG is switched off while Home is open the card stays until Home redraws (cosmetic; `featureOn()` is checked on the next draw).
6. Not verified here: a real-browser pass of the Home card, hold dialog and Settings -> Blocks at desktop and 390 px (the agents' screenshots were not re-taken); the 15 suite skips.
