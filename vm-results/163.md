## Blockers

### B1. A hidden skill stat is disclosed in a check's cue and narrator request

`read.js:77-79,96-106` now correctly retains a hidden `stat1` choice for the rules and marks it hidden; `precall.js:54-57` omits it from the planner's skill listing. But `resolve.js:97,145-153` puts the real skill stat on the rolled check without carrying its visibility, and `cue.js:43-48` always prints `line.pc.stat`. `turn.js:428-434` sends that cue to the narrator under `[Happened]`.

Real-host repro below: Wessel has the skill `Silent Trick`, with `stat1 = dex` and `prompt: false`. The planner sees `Silent Trick (Novice, mana)` and answers `check Wessel | skill: Silent Trick | difficulty: normal`; its parsed plan contains no stat. The actual roll cue says `Wessel — Silent Trick (DEX), normal: ...`, and the actual narrator request contains the same text. The printed `DEX` is the hidden **choice of stat for the skill**, not a roll total or other merely derived outcome. It discloses the association even though Wessel's DEX score itself is public.

This is new in the reviewed commit: with only `read.js` replaced by its `e85c250` version, the same repro sees no skill stat, rolls untrained with Wessel's strongest stat STR, and does not send `Silent Trick (DEX)`. The old behavior has the rules bug from 160 and is not a suitable fix. Preserve and use the real choice for the dice, but carry its visibility through to cue formatting; audit other cue/refusal paths as well.

### B2. A hidden skill resource is disclosed by an empty-resource refusal

The same retention change exposes a second choice through a different output path. `resolve.js:87-99` uses the real hidden `uses1`, as required, but constructs the refusal with `${cap(resource)}` unconditionally. The refusal is included in the cue and in the narrator's actual request. For `uses1 = mana`, `prompt: false`, the repro prints `Wessel cannot use Silent Trick (Mana Empty): rolled without it.` The planner's skill listing and plan do not identify mana as the skill's resource.

In the repro **both** Mana and Stamina are empty. A generic refusal to use the skill is an allowed rules outcome and would not select between those choices, but this text directly names the hidden `mana` choice. With only the parent's `read.js` restored the same setup instead says `Stamina Empty`, the old made-up default; the direct disclosure of the real choice is a regression. Keep the real resource in the rule, while omitting a hidden resource's identity from the refusal. A hidden-resource test should inspect the actual narrator request as well as the cue.

### Reproduce both blockers on the requested head

Run this from the Story Block checkout. Both definitions are accepted by the real host; `kinds = {}` prevents story kinds from writing the hidden fields. The asserts verify the planner and plan omit the choice and the actual cue and narrator request expose it. Roll totals vary.

```sh
node --input-type=module <<'JS'
import assert from 'node:assert/strict';
import { createHost } from './testkit/index.js';
import { LEAN_RPG_TEMPLATES } from './src/v2/lean-rpg/templates.js';
import { success } from './tests/v2/data-modules/helpers.js';
const template = name => structuredClone(LEAN_RPG_TEMPLATES.find(x => x.name === name).definition);
for (const mode of ['stat', 'uses']) {
  const asked = [];
  const host = await createHost({ callModel: async p => {
    asked.push(p); return 'check Wessel | skill: Silent Trick | difficulty: normal';
  } });
  try {
    host.features.set('story-block.rpg', true);
    await host.send('Begin.', 'Opening.');
    const hero = template('Character');
    hero.slug = 'hero'; hero.name = 'Wessel'; hero.state.who.default = 'Wessel';
    hero.state.str.default = 17; hero.state.dex.default = 8;
    if (mode === 'uses') { hero.state.mana.default = 0; hero.state.stamina.default = 0; }
    success(await host.sdk.command('dm.define', { definition: hero }));
    const skills = template('Skills');
    skills.slug = 'wessel-skills'; skills.state.who.default = 'Wessel'; skills.kinds = {};
    skills.state.skill1.default = 'Silent Trick';
    skills.state.stat1.default = 'dex'; skills.state.uses1.default = 'mana';
    skills.state[mode === 'stat' ? 'stat1' : 'uses1'].prompt = false;
    success(await host.sdk.command('dm.define', { definition: skills }));
    const sent = await host.send('I attempt it.', 'A reply.');
    const record = host.ctx.chat.at(-1).extra.storySuite;
    const plan = record.spans.find(s => s.operation?.type === 'rpg.resolve').operation.payload.plan;
    const cue = record.receipts.find(r => r.type === 'rpg.resolve').summary;
    const skillLine = asked.at(-1).split('\n').find(s => s.startsWith('Wessel'));
    const leak = mode === 'stat' ? 'Silent Trick (DEX)' : 'Silent Trick (Mana Empty)';
    assert.ok(cue.includes(leak));
    assert.ok(JSON.stringify(sent.request).includes(leak));
    assert.equal(plan.checks[0][mode], undefined);
    if (mode === 'stat') assert.doesNotMatch(skillLine, /Silent Trick \(Novice, DEX/);
    else assert.doesNotMatch(skillLine, /Silent Trick \([^)]*mana/);
    console.log(JSON.stringify({ mode, skillLine, plan: plan.checks[0], cue }));
  } finally { host.close(); }
}
```
