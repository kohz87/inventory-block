# J2: Write timeline events with an AI (Story Studio) — Sonnet

USER approved the mockup (31 Oct): https://claude.ai/artifact/EanYreZdULFAjKTf2reV2K. Shots and the exact injected
markup/text: `scratchpad/mock-aiwrite/shots/01-ask.png`, `02-paste.png`, `03-drafts.png`, script
`scratchpad/mock-aiwrite/mock.mjs` (it holds the prompt text and an example answer). Build it for real in Studio's
own code and styles. Rules: timeline-briefs/COMMON.md. Repo kohz87/Story_studio, branch `stage17/ai-write` from
`origin/main` (c0df9d1, Studio 0.3.0). Studio stays offline: it never calls any AI or network.

1. **Panel** ("✦ Write with an AI" beside "+ Add event" on the Timeline; opens in the inspector): step 1 Ask —
   the idea (≤ 2000 characters), four include toggles (calendar and start; regions and places; factions and lore
   names from the pack's lorebook entries' names/keys; the existing events), **Copy prompt** (clipboard, with a
   plain fallback if the clipboard is refused), **Save as .txt**, and the full prompt readable in a fold with its
   word count; "Next: paste the answer". Step 2 — paste, **Check it**, per-event ✓ Ready / ⚠ Needs a look with
   plain reasons, **Add N as drafts**.
2. **The prompt** (`src/timeline/ai-prompt.js`, pure): built from the open pack, deterministic, as in the mockup:
   what the events are, the calendar, regions, factions/names, existing events (name + date/after + where), the
   answer format, the rules, the writer's idea, then the full place list at the end. Bound its size (say so in the
   fold if the place list is cut, with the count).
3. **The answer format** (JSON list): `{ name, when: { on: "<Day> <Month>, CY <year>, <dawn|noon|dusk|midnight|HH:MM>" } |
   { after: "<event name>", days|hours|months: N } | "any time", until?: "<date>", where: "anywhere" | [names],
   news (≤500), once (default true), lasting?: { name, state, place?, factions?, summary?, keep? } }`.
   **Reading it** (`src/timeline/ai-answer.js`, pure): tolerant of a code fence or text around the JSON, of a single
   object instead of a list, of month/region/place names in any case; strict about everything it writes. Each event
   is turned into the same spec the event form uses and written with `writeCondition`, so it is exactly what the
   form would write (an "after" event's parent needs a lasting change: in the answer or already in the pack; the
   `time() != null` guard and the capability follow as in 0.3.0). Problems, in plain words: unknown place/region (no
   invented suggestions — say to pick one in the form), date before the start or unreadable, unknown month, an
   "after" naming nothing, a parent without a lasting change, news too long, lasting outside SD's limits
   (`checkLasting`), a name clash with an existing event (offer a unique id).
4. **Drafts**: added to the Timeline with a "draft" chip and dashed outline (and ⚠ on a draft with a problem), held in
   Studio's project state but **left out of the exported pack and of the Problems export check** until kept; they
   survive a reload like the rest of the open project. Opening a draft shows the normal event form plus a banner with
   Keep, Discard and Keep all drafts; a ⚠ draft cannot be kept until fixed (Keep disabled with the reason). Keep and
   Discard are one undo step each.
5. **docs/AI_PROMPT.md**: the same prompt with blanks to fill by hand, and a note that its answer can be pasted into
   Studio's panel. README line, CHANGELOG "Unreleased" (do not bump the version).
