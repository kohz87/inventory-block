Story Studio part 3: character card and lore maker (kohz87/Story_studio, branch studio/part-3 from studio/part-2.5 once 093 is pushed). Goal: a pack author turns the pack they edit in Studio into SillyTavern-ready files, offline, in the same single-file dist page.
1. Narrator card: from the pack's metadata (name, description, start place/time, tone notes) build a SillyTavern character card (Character Card V2 JSON, and PNG with the embedded `chara` tEXt chunk if feasible without network/dependencies) whose description tells the model to write Story Suite `<Changes>` lines (copy the line grammar Story Block documents; do not invent new grammar) and whose first message opens at the pack's start place. Editable fields in the UI before export.
2. Lorebook: export a SillyTavern World Info JSON from the pack's places, factions, NPCs/creatures and items: one entry per record, keys = name + aliases, content from the record's text fields, sensible order/insertion defaults; places carry their region; nothing from outside the pack.
3. Import the other way for authors with an existing lorebook: read a World Info JSON and offer each entry as a draft place/NPC/item the author accepts or skips (never auto-merge); refusals visible.
4. Tests: golden files for the card and lorebook from the Ersveil fixture; deterministic output; zero network; XSS-safe rendering of imported text; browser tests for the three flows. Update docs/STUDIO.md.
Push studio/part-3 (no force, no PRs, no merges). No model names. Output: commits, test counts, screenshots paths of the three flows if the browser tests make them.
